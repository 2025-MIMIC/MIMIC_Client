## 🧾 Project Overview (프로젝트 개요)

**MIMIC**은 “흉내 내다(Mimic)”라는 이름처럼,  
보고 싶은 사람과의 대화 스타일을 학습해 그 사람과 다시 대화하는 듯한 경험을 제공하는 감성 챗봇 서비스입니다.

사용자는 특정 인물(연인, 친구, 가족 등)과의 과거 대화나 말투를 기반으로 챗봇을 생성할 수 있으며,  
이를 통해 **행복했던 기억을 떠올리고 감정적 위로를 받을 수 있는 공간**을 제공합니다.

 </br>
 
> MIMIC은 단순한 대화형 AI가 아닌,  
> **추억과 감정을 보존하는 디지털 기억 저장소**를 목표로 합니다.

## 📱 Key Features (주요 기능)


### 💬 말투 기반 감성 챗봇
- 특정 인물의 말투, 표현 방식, 대화 흐름을 반영한 챗봇 생성
- 실제 대화를 나누는 듯한 자연스러운 응답 제공


### 👤 인물별 챗봇 관리
- 여러 인물을 등록하여 챗봇 개별 관리
- 인물별 성격, 말투, 관계 설정 가능

 ## type 종류

    ``
    feat : 새로운 기능 추가
    fix : 버그 수정
    docs : 문서 수정
    style : 코드 포맷팅, 세미콜론 누락, 코드 변경이 없는 경우
    refactor : 코드 리펙토링
    test : 테스트 코드, 리펙토링 테스트 코드 추가
    chore : 빌드 업무 수정, 패키지 매니저 수정
    rename : 파일 또는 폴더명 수정
    remove : 파일 삭제
    ``

</br>

## 커밋 예시
    ```
    == ex1
    ✨Feat: "회원 가입 기능 구현"

    SMS, 이메일 중복확인 API 개발

    == ex2
    📚chore: styled-components 라이브러리 설치

    UI개발을 위한 라이브러리 styled-components 설치
    ```
